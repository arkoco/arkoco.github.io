如何写出优雅的 CSS

发布于 2026年2月4日 · 编程笔记

在前端开发中，编写可维护的 CSS 是一门艺术。我们不仅要追求视觉上的完美，更要追求代码结构的清晰。

1. 善用变量

通过定义 CSS 变量，可以轻松实现主题切换和统一色调。

:root {
  --primary-color: #f0e6f4;
  --text-main: #333;
}

body {
  color: var(--text-main);
}
